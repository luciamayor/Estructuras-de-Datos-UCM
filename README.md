# Estructuras de Datos Avanzadas

Repositorio con las implementaciones y especificaciones formales de estructuras de datos desarrolladas durante el Grado de Matemáticas con especialización en Ciencias de la Computación (UCM). 

Este proyecto combina la programación eficiente y orientada a objetos (C++) con la especificación algebraica y lógica de reescritura (Maude).

## Contenido del Repositorio

El código está organizado en los siguientes módulos fundamentales según su tipo abstracto de datos (TAD):

* **Especificacion-implementacion-datos**: Diseño formal y conceptos base de tipos de datos abstractos.
* **Pilas**: Implementación de estructuras LIFO (Last In, First Out).
* **Colas**: Implementación de estructuras FIFO (First In, First Out) y sus variantes.
* **Listas**: Estructuras secuenciales, enlazadas y doblemente enlazadas.
* **Arboles**: Estructuras jerárquicas no lineales (árboles binarios, árboles de búsqueda, etc.).

## Tecnologías Utilizadas

* **C++**: Implementación a bajo nivel, análisis de eficiencia y gestión de memoria.
* **Maude**: Especificación formal y verificación.
